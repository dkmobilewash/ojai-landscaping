# Images

This folder is reserved for real photography (hero background, project galleries,
team photos, etc.).

Until real photos are supplied, the site uses CSS gradients and inline SVG
placeholders in place of images — no `<img>` tags reference this folder yet, so
the site runs with zero broken links straight from `index.html`.

Suggested slots for future photos:
- `hero.jpg` — warm Ojai hillside / completed landscape for the hero background
- `project-*.jpg` — before/after project gallery
- `team.jpg` — the crew on site
